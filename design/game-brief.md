# Game Brief: Player One (играбельное резюме)

**One-sentence pitch:** Резюме, собранное как 60-секундная казуалка для HR — оно само доказывает главный навык кандидата: проектировать онбординг, награды и монетизацию для неискушённого игрока.

## Core loop
- HR открывает «уровень»-секцию → получает микронаграду: факт, цифру, кейс
- Награда подсвечивает следующий узел карты → тянет листать дальше
- Финал: CTA «Написать» + бонус-пасхалка через «rewarded ad»

## Player goal & fail state
- **Win:** HR за 1–2 минуты решает «хочу созвон» и жмёт CTA.
- **Fail:** за 30 секунд не понял, кто кандидат и зачем листать. Дизайн убирает fail: мгновенная ясность «кто/зачем», ноль фрустрации, всё с первого тапа.

## MVP (7)
1. **Сплэш «▶ ИГРАТЬ»** — имя, должность, one-liner; ясно за 3 сек
2. **Онбординг-туториал** — 2 ненавязчивые подсказки (👆 тапни)
3. **Карта уровней** — карьерный таймлайн: ноды-секции + прогресс
4. **Уровень «Опыт & Unity»** — игры-карточки (скриншот, роль, метрика, ссылка APK/стор), скриншоты работы в Unity
5. **Уровень «Баланс & LiveOps»** — кейсы с цифрами и гипотезами
6. **Уровень «Монетизация»** — rewarded-пасхалка → бонус-секция
7. **Финал** — CTA (tg/email), кнопки «PDF / ГДД», fallback-версия без JS

## Out of scope
- Настоящая мини-игра с геймплеем (концепт-вариант 2, не сейчас)
- A/B-переключатель, бэкенд, CMS, аналитика, EN-версия, звук по умолчанию

## Build order
1. Каркас + механика карты уровней (самое рискованное — проверяем на телефоне сразу)
2. Rewarded-пасхалка
3. Контент секций (нужны материалы кандидата)
4. Сплэш, онбординг, CTA-финал
5. Fallback-версия + мобайл-полировка

---

**Who it's for / what they feel:** HR или основатель студии (команда — 7 человек) с телефона; чувствует «умеет упаковать сложное просто и со вкусом — хочу созвон».

**Art & audio direction:** сочный casual-мобильный UI: chunky-кнопки, HUD-иконки, яркие акценты; звук выключен по умолчанию — опциональный тумблер 🔊.

**Reference game:** их собственный *Prison Escape: Fun Run* — визуальная рифма «я изучил ваш продукт», MVP берёт его мгновенный онбординг и наградную петлю, без мета-прогрессии.
