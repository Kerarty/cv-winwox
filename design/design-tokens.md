# Дизайн-токены — cv-winwox «Player One»

> Грундинг: мир их игры (Prison Escape: Fun Run — ночная космическая станция, лазерные рельсы, оранжевые робы) + бренд сайта студии (#bf570c, #ffe6d7, #ffcaab, #d07d13, #a42903). Тёплое на холодном — центральный приём.

## Палитра (6 именованных)

| Токен | Hex | Роль |
|---|---|---|
| `--void` | `#0B1220` | космос за окнами станции: фон страницы |
| `--hull` | `#1A2537` | панели и карты секций, корпус уровня |
| `--hull-2` | `#243247` | вложенные блоки, слоты инвентаря |
| `--suit` | `#F2762E` | оранжевый робы заключённого — главный акцент: CTA, прогресс, «кандидат» |
| `--brand` | `#BF570C` | тёмный оранжевый бренда студии — ховеры, границы акцента |
| `--laser` | `#3EE6C1` | неон энергетических рельсов — «открыто/успех/чекпоинт» |
| `--alert` | `#FF4D5E` | красный лазерных заграждений — честный блок, риски |
| `--amber` | `#FFC53D` | золото наград — ачивки, монеты-факты |
| `--star` | `#FFF3E4` | тёплый белый — основной текст (на тёмном всегда тёплый, не чистый #fff) |

Правило контраста: тёплое (suit/amber) = кандидат и награды; холодное (void/hull/laser) = станция/процесс. Кандидат «светится» оранжевым на тёмной станции — визуальный тезис резюме.

## Типографика

- **Дисплей: Baloo 2** (Bold/ExtraBold) — chunky, округлый, «сочный casual»; кириллица есть. Заголовки секций, кнопки, HUD-цифры.
- **Текст: Golos Text** (Regular/Medium) — спокойный, отлично держит мелкий кегль на тёмном. Абзацы, факты, подписи.
- Шрифты влитые woff2 base64 (2 файла × 2 начертания), 0 сетевых запросов.
- Шкала: 12 / 14 / 16 / 20 / 28 / 40. Интерлиньяж текста 1.5; дисплей — 1.1.
- НЕ: ALL-CAPS eyebrows, влитое выделение одного слова в заголовке, моно для данных.

## Layout

Mobile-first: контентная колонка = «уровень станции».

```
Мобайл                              Десктоп
┌────────────────────────┐          ┌───┬────────────────┬───┐
│ ⛓ ДОСЬЕ №  ⌂▮▮▯▯ ⏱ 🔊 │          │ ★ │                │ ★ │
│────────────────────────│          │   │   УРОВЕНЬ      │   │
│   ШЛЮЗ 01 — ОПЫТ       │          │звё│   (колонка     │звё│
│  ╔══════════════════╗  │          │зды│   ~460px)      │зды│
│  ║ карточка факта   ║  │          │   │                │   │
│  ╚══════════════════╝  │          │   │  [CTA]         │   │
│   ▼ следующий шлюз     │          ├───┴────────────────┴───┤
│  ●━━●━━★━━○──○  путь   │          │ HUD-полоса + путь внизу │
│ [Сразу к досье]  [PDF] │          └─────────────────────────┘
└────────────────────────┘
```

- HUD-полоса: номер досье, прогресс-чекпоинты, таймер «внимания HR» (считает секунды — приём из cv-vizor), тумблер звука 🔊.
- Карта пути внизу HUD: чекпоинты-ноды, пройденные горят лазерным неоном, текущая пульсирует.
- «Сразу к досье» — постоянная кнопка-выход: рёбрам канона playable «нельзя проиграть».
- Выравнивание: заголовки слева, контент слева; кнопки и HUD — по центру полосы.
- Один orchestrated-момент: **открытие шлюза** на старте (две створки разъезжаются, кандидат-роб выглядит из проёма). Дальше motion только ответом на действие: раскрытие секции, штамп «ПРОЙДЕНО», вылет монеты-факта.

## Компоненты

- **Шлюз-секция**: панель hull со скошенными верхними углами (катанка корпуса), оранжевые заклёпки по краям.
- **Карточка факта** = «трофей»: hull-2, слева оранжевая полоса, иконка-иконка инвентаря; за неё начисляется монета-факт.
- **Rewarded-пасхалка**: кнопка «▶ Смотреть рекламу» (оранжевая) → 3-сек фейковый преролл «Реклама Win Wox» → открывает бонус-секцию «Что я сделал бы в Prison Escape» (3 гипотезы с метриками). Подпись мелко: «Да, это шутка про rewarded. Но вы бы её тоже поставили».
- **Честный блок**: секция с красной каймой alert «ЗАПРЕТНАЯ ЗОНА» — прямое «чего у меня пока нет».
- **Финал**: табличка «ГОДЕН К НАЙМУ» + CTA.

## Принципы

1. Тёплое на холодном: кандидат — оранжевый свет в тёмной станции; нигде наоборот.
2. Язык их игры — не декорация: каждый гейм-элемент = требование вакансии (шлюз = секция, рельсы = путь карьеры, роб = кандидат, ловушка = миф о джуне).
3. Каноны playable: 1 файл, 0 запросов, старт с 1 клика, путь до PDF ≤ 60 сек, HR нельзя проиграть.
4. Один смелый момент — шлюз-интро. Остальное дисциплинированно.
5. Честный блок обязателен — подпись серии.

## Самопроверка против генерик-дефолтов

- Тёмный фон + неон — похож на «near-black + acid green» дефолт, НО здесь это буквальный мир их игры (ночная станция, энергетические рельсы), и главный акцент — тёплый оранжевый бренда студии, а не кислотный зелёный. Проверка пройдена с оговоркой: неон-бирюза держим строго вторичной, не CTA.
- Cream+serif+terracotta — нет. SaaS-карточки с одним border-radius — нет: скошенные углы, заклёпки, разная геометрия секций. Номера-маркеры — только чекпоинты пути (там реальная последовательность).
