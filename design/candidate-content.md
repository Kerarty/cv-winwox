## 3. Проекты (факты для секций)

### echoloop-playble — Unity 6 + URP, C#
Головоломка о времени: петля, эхо прошлых проходов. 8 уровней, прогрессия без туториалов; правило дизайна: «точка эха достижима ходом, награда эха — нет». 26 EditMode-тестов проходимости, 0 бинарных ассетов (арт/звук кодом). геймпад + клавиатура.
→ Закрывает: Unity на уровне геймдизайнера, левел-дизайн, кривая сложности. https://github.com/Kerarty/echoloop-playble

### playble-ads — SDK, TypeScript
Движко-независимый SDK для HTML5 playable-рекламы: core + адаптеры под рекламные сети, engine на PixiJS, симулятор контейнера, spec-check против требований сетей. 194 юнит-теста, CI. v1.0.0.
→ Закрывает: понимание рекламной монетизации как бизнес-модели (ключ к «рекламной монетизации» вакансии). https://github.com/Kerarty/playble-ads

### splash-kitty-playable-ad — PixiJS 8 + matter.js
Playable-креатив: нарисуй линию — капли стекают в кота-стакана. 683 КБ (лимит 5 МБ), 0 сетевых запросов, первый интерактив < 1 сек, 3 уровня ~30 сек, 60 FPS, WebAudio-синтез звука.
→ Закрывает: рекламная монетизация, конверсионные механики («мягкий фейл», петля «ещё раз»). https://kerarty.github.io/splash-kitty-playable-ad/

### playable-ad-mob-rush — PixiJS 7, crowd runner
472 КБ один файл, MRAID (viewableChange→пауза, mraid.open()), воронка trackEvent (tutorial_start/complete, run_failed, level_complete, cta_click), seeded RNG (детерминированный показ), пулы объектов, 60 FPS, все звуки WebAudio.
→ Закрывает: рекламная монетизация + аналитическая воронка UA. https://kerarty.github.io/playable-ad-mob-rush/

### «Королевства Эридора» — настольная тактика, 4 фракции
Спроектировал с нуля: боевые механики, захват территорий, баланс юнитов. 15+ плейтест-сессий, итеративный баланс по принципу, схожему с live-ops анализом после релиза.
→ Закрывает: баланс, наигровка, работа с обратной связью.

### Концепт-документ градостратегии — полный GDD
Механики, прогрессия, баланс ресурсов, арт-стиль; структура «под передачу команде».
→ Закрывает: «идея → ГДД → постановка задач» (прямое требование). 12 страниц GDD (Neon Carnival) — второй пример.

### Neon Carnival — слот-демо (cv-belatra)
5×3, 9 линий, Wild, Scatter, стейт-машина, бонус Prize Parade, Feature Tuning (живая лаборатория параметров), GDD из 12 вкладок.
→ Закрывает: монетизация, документация решений. https://kerarty.github.io/cv-belatra/

### Баланс-лаборатории и тюнеры (серия CV)
